# NetQuest - Computer Networks Learning Platform (KARE Edition)

A gamified, interactive educational platform for college students mastering Computer Networks.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
