Key terms
Interface – a router port. Each one needs its own IP in its own network.
no shutdown – switches a port on; ports are administratively down by default.
Default gateway – the router's LAN address; hosts send off-network traffic to it.
Connected route (C) – added automatically when an interface is up with an IP.
Static default route (S*) – manual route 0.0.0.0/0 for “everything else”.
