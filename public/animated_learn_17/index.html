Key terms
ARP – finds the MAC address that goes with a known IP address, inside one network.
MAC address – the hardware address a switch uses to deliver an Ethernet frame.
Broadcast – frame to FF:FF:FF:FF:FF:FF; the switch floods it to every port.
ARP cache – remembered IP→MAC pairs, so the shout is not repeated for every packet.
RARP – the reverse: knows the MAC, asks for the IP.
