    Key terms
    Router – a device that reads the destination IP and forwards the packet to the next hop.
    Routing table – the router's map: destination network → next hop + interface.
    TTL – hop limit. Every router subtracts 1; at 0 the packet is dropped (stops endless loops).
    NAT – rewrites a private address (192.168.x.x) into a public one at the network edge.
    AS / BGP – each ISP is an Autonomous System; BGP lets ASes exchange routes between them.
